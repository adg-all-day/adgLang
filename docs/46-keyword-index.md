# Keyword Index

These words are reserved in adgLang.

- `frame`
- `struct`, `spec`, `enum`
- `return`
- `if`, `else`
- `loop`
- `break`, `continue`
- `switch`, `case`, `default`, `fallthrough`
- `import`, `export`
- `try`, `catch`, `throw`
- `local`, `global`, `const`
- `nullptr`, `true`, `false`
- `match`, `type`, `cast`, `sizeof`
- `extern`, `from`, `as`
